# Friend Reference — Eco OOP Practices

This directory is separate from the main practice directory.

- practice/ contains starter exercises with TODO comments.
- answers/ contains completed reference solutions.

Try each exercise first, then compare your attempt with the matching answer. The solutions show one reasonable approach, not the only possible approach.

Lessons: 01 Classes and objects; 02 Attributes and methods; 03 Encapsulation; 04 Composition; 05 Dataclasses; 06 Object collaboration; 07 Market simulation; 08 Market transactions; 09 Reading receipts.
